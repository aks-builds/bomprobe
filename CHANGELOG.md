# Changelog

## 1.0.0

Initial stable release.

- 126 quality checks for CycloneDX and SPDX
- Three compliance profiles: NTIA, BSI TR-03183, EU CRA
- 16 output formats: text, json, markdown, csv, sarif, html, junit, gitlab, github, badges, and more
- Scoring engine with weighted checks and A-F grading
- Config presets: strict, moderate, minimal, ci, audit
- Three-layer config: env vars, config file, CLI flags
- Zero npm dependencies
- Node.js 18+ with built-in test runner
